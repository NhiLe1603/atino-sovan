1 Chân dung ứng viên

Điền chân dung (hoặc dán từ AI), rồi bấm Đẩy vào phiếu →. Phiếu ở giữa sẽ tự dựng theo chân dung này.

Những thứ thiếu 1 là loại ngay, không cần chấm điểm. VD: nhận ca xoay/ca tối · ở gần nơi làm · đi làm được đúng ngày · lương mong muốn trong khoảng. Chỉ đặt 3–4 cái — nhiều quá sẽ mất nguồn.

CWC = 3 nhóm cần nhìn ở ứng viên: Can do (làm được việc không) · Want to (có muốn làm & gắn bó lâu không) · Culture fit (thái độ/hợp văn hoá không). Sơ vấn nặng Want to; Can do & Culture fit chỉ lấy tín hiệu (HM kiểm sâu). Đặt 4–6 tiêu chí, cột % cộng lại = 100. Câu hỏi nên bắt đầu bằng “Kể về một lần…”.

⚡ Cách nhanh: dùng AI tạo chân dung từ JD

3 bước, không cần biết gì: (1) bấm Copy prompt. (2) Mở Claude/ChatGPT, dán prompt, thay chữ [DÁN JD VÀO ĐÂY] bằng JD của bạn → gửi. (3) Copy TOÀN BỘ kết quả AI, dán xuống ô "Kết quả AI" → bấm Tự điền vào form. Form tự điền, bạn KHÔNG phải copy từng ô.

3 Kết quả & Lưu

Nhật ký đã lưu (phiên này)
Chưa có.
Hướng dẫn: cả team lưu chung về 1 Google Sheet (~5 phút, không cần API)
  1. Tạo 1 Google Sheet mới trong Drive của bạn.
  2. Menu Extensions → Apps Script, xoá code cũ, dán đoạn dưới, bấm Save.
  3. Deploy → New deployment → chọn type Web app · Execute as: Me · Who has access: Anyone → Deploy → copy Web app URL.
  4. Dán URL vào dòng const GS_URL="..." ở đầu phần <script> (để cả team dùng chung 1 Sheet, khỏi phải tự dán) — hoặc dán vào ô "Google Apps Script URL" ở trên nếu chỉ dùng riêng.
  5. Bấm Lưu lên Google Sheet → mỗi phiếu thành 1 dòng trong Sheet (nằm trong Drive của bạn).
function doPost(e){
  var lock = LockService.getScriptLock();   // tránh ghi đè khi nhiều người lưu cùng lúc
  lock.waitLock(20000);
  try {
    var ss = SpreadsheetApp.getActiveSpreadsheet();
    var sh = ss.getSheetByName('SoVan') || ss.insertSheet('SoVan');
    if (sh.getLastRow() === 0)
      sh.appendRow(['Thời gian','Vị trí','Ứng viên','Người sơ vấn','Ngày','Điểm','Kết luận','Chi tiết']);
    var d = JSON.parse(e.postData.contents);
    sh.appendRow([new Date(), d.vitri, d.ten, d.nguoi, d.ngay, d.diem, d.ketluan, d.chitiet]);
    return ContentService.createTextOutput('ok');
  } finally { lock.releaseLock(); }
}

Lưu ý: do trình duyệt chặn (CORS), trang không đọc được phản hồi — nên sau khi bấm, kiểm tra Sheet để chắc chắn đã có dòng mới. Nếu chưa muốn set up, cứ dùng Tải JSON rồi kéo file vào thư mục Drive.
